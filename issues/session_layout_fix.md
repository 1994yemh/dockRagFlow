# 任务：会话调试沙盒三栏布局物理拓宽与文案全量回滚

## 1. 上下文背景 (Context)
- 用户反映在此前的聊天界面重构中，左侧“会话列表”部分被拉窄（`lg:col-span-2`）后导致其中的文字与按钮描述出现缩水和删减，极大地影响了操作体验。
- 用户指出，希望保留 `2:7:3` 的比例，但是整体页面左右两边有大量多余的空白物理宽度，应当通过拓宽最外层主包裹容器来利用这些宽度。
- 这样，即使保持 `2/12` 的网格占比，在更大的可用物理像素宽度下，左侧也能完美展示全部未删减的按钮和中文字符，不再显得拥挤或字数缩水。

## 2. 执行计划 (Execution Plan)
- **步骤 1**：拓宽 `index.html` 的 `#app` 根容器。将 `max-w-[90%] 2xl:max-w-[1500px]` 升级为 `w-full max-w-[96%] 2xl:max-w-[1750px] 3xl:max-w-[1950px] mx-auto`。
- **步骤 2**：对左侧会话列表的所有按钮文字、卡片动作、状态提示及标题进行回滚：
  - 标题：“调试助理” -> **“当前调试的目标助理”**
  - 按钮：“切换” -> **“切换助手”**
  - 标题：“会话列表” -> **“历史会话列表”**
  - 按钮：“+ 新建” -> **“+ 新建会话”**
  - 按钮：“改名” -> **“重命名”**
  - 按钮：“删” -> **“删除”**
  - 空状态：“暂无会话” -> **“暂无会话。请点击上方“新建会话”开启全新对话。”**
  - 清空按钮：“清空会话” -> **“一键清空该助手所有会话”**
- **步骤 3**：验证与测试，确保布局拉伸自然，按钮无折行或重叠，交互体验恢复最佳状态。
